**You do not need to install anything.** Every tool in this course runs in a web browser, and none of them needs an account. This page is a short checklist so that you are ready for Week 1.

## What you need

::::::::::::::::::::::::::::::::::::::: discussion

### Before Week 1

- A computer with an up-to-date web browser: **Chrome**, **Edge**, **Firefox** or **Safari**. A work laptop is fine.
- A reliable internet connection that can play **YouTube** videos.
- A way to write and save your work: any text editor, Word or Google Docs. You submit each week's portfolio as a Markdown (`.md`), Word or PDF file.
- A way to take a screenshot: **Windows key + Shift + S** on Windows, or **Cmd + Shift + 4** on a Mac.

:::::::::::::::::::::::::::::::::::::::::::::::::::

## The free browser tools you will use

| Week | Tool | What it is for |
|---|---|---|
| 2 | [HexEd.it](https://hexed.it/) | Looking at the bytes inside a file. Files are opened in your browser, not uploaded. |
| 2 | [CircuitVerse](https://circuitverse.org/simulator) | Building logic circuits. Use it as a guest. |
| 3 | [JSLinux](https://bellard.org/jslinux/) | A real Linux system running inside your browser |
| 4 | [diagrams.net](https://app.diagrams.net/) | Drawing flowcharts and diagrams |
| 4 | [Little Man Computer](https://peterhigginson.co.uk/lmc/) | A simple simulated CPU |
| 5 | Your browser's **developer tools** and **certificate viewer** | Seeing requests, status codes and certificates |
| 5 | [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/) | Looking up DNS records |
| 5 | [Google Phishing Quiz](https://phishingquiz.withgoogle.com/) | Practising spotting phishing emails. Use a made-up name and email. |
| 5 | [CyberChef](https://gchq.github.io/CyberChef/) | Trying encoding and hashing |
| 5 | [httpstatus.io](https://httpstatus.io/) | Checking status codes if developer tools are blocked |

:::::::::::::::: callout

### On a work laptop

Your employer's IT team may block some tools or settings. That is fine:

- Each task says what to do if a tool is blocked, and you will not be marked down.
- If there is no fallback, try a home or library computer, and tell your tutor.

## Course files

Some practice tasks use files, such as worksheets, a server log and three "mystery" files. Each task links to the files it needs, or you can download them all at once in the [course files zip](../episodes/data/course-files.zip). Unzip it into a folder you can find again.

## Privacy in this course

You will never be asked for personal details. **Do not record** your computer's serial number, device name, user name or IP address, or any passwords, in your work. All the businesses and people in the case studies are invented.
