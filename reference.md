## Glossary

Algorithm
:   A precise, step-by-step set of instructions for solving a problem (Week 4).

ALU (arithmetic logic unit)
:   The part of the CPU that does calculations and comparisons (Week 1).

Application software
:   Software that helps a person do a task, such as a web browser or a spreadsheet (Week 3).

ASCII and Unicode
:   Codes that give every character a number. ASCII covers English; Unicode covers every language and emoji (Week 2).

Binary
:   The base-2 number system, using only 0 and 1. Computers store everything in binary (Week 2).

Bit and byte
:   A bit is one binary digit. A byte is 8 bits (Week 2).

Certificate
:   A digital document that proves a website's identity, signed by a trusted certificate authority (Week 5).

CIA triad
:   The three goals of security: confidentiality, integrity and availability (Week 5).

Cloud computing
:   Using computing resources in someone else's data centre over the internet, and paying for what you use (Week 6).

Command line
:   A way of controlling a computer by typing commands (Week 3).

Compiler
:   A program that translates a whole program into machine code before it runs (Week 4).

CPU (central processing unit)
:   The part of a computer that follows instructions, using the fetch-decode-execute cycle (Week 1).

Data and information
:   Data is raw facts. Information is data processed so that it means something (Weeks 1 and 6).

Data sovereignty
:   The idea that data is subject to the laws of the country where it is stored (Week 6).

Digital footprint
:   The trail of data you leave behind online, both active (what you share) and passive (what is collected about you) (Week 6).

DNS (Domain Name System)
:   The system that turns names such as `www.abc.net.au` into IP addresses (Week 5).

Encryption
:   Scrambling data so that only someone with the key can read it (Week 5).

Essential Eight
:   Eight strategies from the Australian Signals Directorate that protect organisations from common cyber attacks (Week 6).

File signature
:   The first few bytes of a file, which show what kind of file it really is (Week 2).

Flowchart
:   A diagram of an algorithm, using shapes for steps and decisions (Week 4).

Hashing
:   Making a fixed-length, one-way "fingerprint" of data, used to check it has not changed (Week 5).

Hexadecimal (hex)
:   The base-16 number system, using 0 to 9 and A to F. One hex digit stands for 4 bits (Week 2).

HTTP and HTTPS
:   The rules for requesting web pages. HTTPS is the encrypted version (Week 5).

IaaS, PaaS and SaaS
:   Cloud service models: renting infrastructure, a platform, or finished software (Week 6).

Interpreter
:   A program that translates and runs a program one statement at a time (Week 4).

IP address
:   A number that identifies a device on a network, such as `192.168.1.20` (Week 5).

Least privilege
:   Giving every person and program only the access they need, and no more (Week 3).

Logic gate
:   A tiny circuit that combines bits using a rule such as AND, OR, NOT or XOR (Week 2).

Malware
:   Any harmful software, including viruses, worms, trojans, spyware and ransomware (Week 5).

MFA (multi-factor authentication)
:   Logging in with two or more kinds of proof, such as a password and a code on your phone (Week 5).

Operating system
:   The system software that manages the hardware, programs, files and users, such as Windows, macOS or Linux (Week 3).

Personal and sensitive information
:   Personal information identifies a person. Sensitive information, such as health information, needs extra care under the Privacy Act (Week 6).

Phishing
:   Fake messages that trick people into clicking, paying or giving away details (Week 5).

Port
:   A number that identifies a service on a computer, such as 443 for HTTPS (Week 5).

Pseudocode
:   An algorithm written in structured plain English, before any programming language is used (Week 4).

RAM and ROM
:   RAM is fast, temporary working memory. ROM holds the start-up instructions and keeps them when the power is off (Week 1).

Router and switch
:   A switch connects devices inside a network. A router connects networks and chooses the path for data (Week 5).

Status code
:   A number a web server sends back to say what happened, such as 200 (OK) or 404 (not found) (Week 5).

Storage
:   Where data is kept when the power is off, such as an SSD or a hard disk (Week 1).

System software
:   Software that runs the computer itself: the operating system, drivers and utilities (Week 3).

Trace table
:   A table used to follow an algorithm by hand, recording each variable at each step (Week 4).
